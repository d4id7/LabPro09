## Часть 3. Ошибка границ

### Шаг 4. Ищем ошибку

1. Успели вывестись все элементы массива - `10`, `20`, `30`
2. `i = 3`, `Length = 3`
3. Программа завершилась, потому что значение `i` вышло за пределы индекса
4. Нужно заменить `<=` на `<`, тогда `i` остановится на `i = 2 = Length - 1`

## Контрольные вопросы

**ПР9. Ответы на контрольные вопросы**

1. `0`
2. `Length - 1`
3. Потому что иначе `i` будет принимать значение большее максимального индекса `Length - 1`, т.е. `i = Length`, что приведёт к ошибке `IndexOutOfRangeException`
4. `for` удобнее использовать, когда нам нужен индекс элемента, а `foreach`, когда требуется только значение
5. В случае с массивами в метод передаётся ссылка на массив, а не значение его элементов, что позволяет изменять их
6. Потому что массив может состоять из отрицательных чисел. В таком случае, значение `max = 0` будет всегда `0` (и наоборот для массива из положительных элементов, `min = 0` будет всегда `0`)
7. `int[] numbers = [1, 2, 3]` создаёт массив в переменной `numbers` с элементами 1, 2, 3. `int[] numbers = { 1, 2, 3 }` делает тоже самое, такой синтаксис используется в более старых версиях C#

_Необязательный вопрос для любознательных:_ с `ref` метод получит ссылку на саму переменную, что позволит присвоить ей новое значение (например, было `int[] nums = [1, 2, 3]`, а стало `int[] nums = [3, 5, 1, 6, 4]`). Изменились не элементы массива, а сам массив
